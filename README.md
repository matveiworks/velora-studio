# VELORA — Premium Beauty Studio

Односторінковий сайт-візитка преміальної beauty-студії. Статичний HTML/CSS/JS, без збірки та залежностей.

## Структура

- `index.html` — розмітка сторінки
- `css/styles.css` — стилі
- `js/script.js` — мобільне меню, скрол-анімації та форма запису
- `images/` — фото студії (поки не додані — плейсхолдери намальовані на CSS/SVG)

## Локальний перегляд

```
python3 -m http.server 8000
```

Потім відкрити `http://localhost:8000`.

## Деплой

Сайт готовий до деплою на Vercel (статичний сайт, конфіг не потрібен) автоматично при push у гілку `main`.
